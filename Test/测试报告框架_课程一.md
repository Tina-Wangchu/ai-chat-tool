### 测试用例 2.3：流式 vs 非流式对比

**测试目的**：对比流式输出和非流式输出的用户体验差异

#### 测试设计

**测试问题**：`给我讲一个关于编程的小故事，大约200字。`

**测试条件**：
- 流式模式：`stream=True`
- 非流式模式：`stream=False`

#### 测试数据记录

**流式模式**

| 指标 | 数值 |
|:-----|:----:|
| 首字响应时间 | 秒 |
| 完整响应时间 | 秒 |
| 用户感知延迟 | （低/中/高） |
| 用户体验 | （好/中/差） |

**输出效果**：
- 文字逐字出现，类似打字效果
- 可以提前看到内容，减少等待焦虑
- 适合长文本生成

**非流式模式**

| 指标 | 数值 |
|:-----|:----:|
| 首字响应时间 | 秒（=完整响应时间） |
| 完整响应时间 | 秒 |
| 用户感知延迟 | （低/中/高） |
| 用户体验 | （好/中/差） |

**输出效果**：
- 一次性显示全部内容
- 等待期间无反馈
- 适合短文本

#### 对比结论

| 对比维度 | 流式模式 | 非流式模式 | 推荐 |
|:--------|:--------|:----------|:-----|
| 响应时间（首字） | 秒 | 秒 | 流式更快 |
| 完整时间 | 秒 | 秒 | 基本相同 |
| 用户体验 | （好/中/差） | （好/中/差） | |
| 适用场景 | 长文本、对话 | 短文本、API调用 | |

**测试结论**：
- 流式模式在用户体验上优于非流式模式
- 首字响应时间显著减少，提升交互感
- 建议默认启用流式模式
