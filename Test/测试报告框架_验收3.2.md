## 使用说明

### 如何使用此测试报告框架

1. **复制模板**：将此文件复制为 `测试报告_实际测试日期.md`
2. **填写测试数据**：
   - 填写测试时间、测试人员等基础信息
   - 逐个执行测试用例，记录实际响应和截图
   - 填写每个检查点的实际结果和状态
3. **统计结果**：
   - 自动计算通过率（或手动填写）
   - 填写响应时间统计
   - 记录发现的问题
4. **撰写结论**：
   - 根据测试结果撰写测试结论
   - 提出改进建议
5. **附加材料**：
   - 粘贴截图和日志片段
   - 附上 PDF 报告样本

### 测试准备清单

测试前请确认：
- [ ] Hermes Agent 已安装并正常运行
- [ ] 微信对接已配置并测试通过
- [ ] 邮件 SMTP 配置正确
- [ ] 学术 API 可正常访问
- [ ] 所有环境变量已设置
- [ ] 日志系统正常工作
- [ ] 测试邮箱可访问
- [ ] 微信测试账号就绪

### 常见问题处理

**问题1：微信消息无响应**
- 检查微信对接服务是否运行
- 检查 Hermes Agent 日志
- 尝试重启微信对接服务

**问题2：邮件发送失败**
- 检查 SMTP 配置
- 检查邮箱是否开启 SMTP 服务
- 检查网络连接

**问题3：论文检索无结果**
- 检查学术 API 是否可访问
- 尝试更换检索关键词
- 检查 API 密钥是否有效
